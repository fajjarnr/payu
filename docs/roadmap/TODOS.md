Di `frontend/web-app/src/app/[locale]/backoffice/kyc/page.tsx`, `fraud/page.tsx`, dan `customers/page.tsx`, input pencarian (`Cari nasabah...`, `Cari kasus...`, `Cari tiket...`) hanya dirender sebagai `<Input ... />` tanpa `value`, `onChange`, atau parameter query apa pun ke `BackofficeService`. Akibatnya operator dapat mengetik sepuasnya tetapi hasil list tidak pernah berubah; UI menampilkan affordance pencarian yang sama sekali tidak bekerja.
- **[BUG-FE-036]** Counter badge pada halaman KYC, Fraud, dan Customer Ops menampilkan angka hardcoded yang tidak pernah mengikuti data backend. `frontend/web-app/src/app/[locale]/backoffice/kyc/page.tsx` menulis `Tertunda: 24`, `fraud/page.tsx` menulis `Kritis: 12`, dan `customers/page.tsx` menulis `Open: 42` secara literal. Karena halaman-halaman itu justru memuat data list secara live, badge count palsu ini menyesatkan operator dengan indikator prioritas yang bisa berbeda dari keadaan riil sistem.
- **[BUG-FE-037]** Halaman compliance mencampur tabel audit live dengan CTA filter/export yang sepenuhnya inert. Di `frontend/web-app/src/app/[locale]/backoffice/compliance/page.tsx`, data audit memang dimuat lewat `useAuditReports()` dan `useFailedAccessAudits()`, tetapi tombol `More Filters`, `Last 24 Hours`, dan `Export Audit Report` dirender tanpa `onClick`, query update, maupun download action. Hasilnya operator melihat toolbar compliance yang tampak siap dipakai, padahal mereka tidak bisa mengubah cakupan audit ataupun mengekspor laporan yang ditampilkan.
- **[BUG-FE-038]** Halaman compliance menampilkan sebagian metrik regulatori yang sepenuhnya hardcoded walau halaman lain di kartu yang sama memakai data live. Pada `frontend/web-app/src/app/[locale]/backoffice/compliance/page.tsx`, `Security Score` dipatok ke `98/100` dan `Regulatory Status` dipatok ke `Compliant`, sementara kartu lain di grid memakai `auditLogs.length` dan `failedAccessData`. Campuran antara metrik riil dan metrik statis ini berbahaya karena memberi kesan bahwa dashboard compliance sudah menghitung posture/regulatory state secara live padahal dua indikator utamanya hanyalah placeholder permanen.
- **[BUG-FE-039]** Navigasi backoffice di mobile/tablet tidak pernah muncul walaupun tombol hamburger aktif. Pada `frontend/web-app/src/app/[locale]/backoffice/layout.tsx`, state `isSidebarOpen` hanya di-set lewat tombol `Menu` (`onClick={() => setIsSidebarOpen(true)}`), tetapi file tidak pernah merender drawer, overlay, ataupun sidebar mobile berdasarkan state tersebut. Akibatnya seluruh area backoffice praktis kehilangan navigasi di viewport non-desktop: user bisa menekan hamburger, tetapi tidak ada menu yang pernah muncul.
- **[BUG-FE-040]** Chrome global backoffice menampilkan search dan notification affordance yang inert. Di `frontend/web-app/src/app/[locale]/backoffice/layout.tsx`, field `Universal Admin Search...` hanya berupa `<Input>` tanpa state, `onChange`, atau query binding, sementara tombol icon notifikasi `Bell` juga tidak memiliki `onClick`/link/dropdown apa pun. Karena keduanya berada di layout shared untuk semua halaman admin, operator melihat kontrol global yang tampak inti tetapi tidak pernah melakukan aksi sama sekali.
