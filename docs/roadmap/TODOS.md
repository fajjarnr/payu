### Test Audit Focus (March 16, 2026)

- `tests/contract/` is stale against current auth, wallet, and transfer contracts.
- `tests/infrastructure/` still validates retired Docker Compose + Zookeeper assumptions instead of the active local-podman topology.
- `tests/load-tests/` is documented as canonical but its POM/source paths do not run the actual current Gatling simulations.
- `tests/performance/`, `tests/regression/`, and `tests/security/` still contain obsolete auth, wallet, and documentation assumptions.
- Repeated RTK-style passes keep finding new bugs, so the current backlog is still not exhaustive and the repo should be treated as under-audited rather than bug-complete.
