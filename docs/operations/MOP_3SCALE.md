# Method of Procedure (MOP) — Red Hat 3scale v2.15 Migration

This document outlines the detailed step-by-step checklist for migrating **Red Hat 3scale API Management (v2.15)** from `payu-onprem` to `payu-prod`. All steps must be executed manually.
